# 使用说明（管理员与玩家）

## 管理员功能

- 放置售票机/检票机：使用命令 `/givemachine <type>`（例如 `ticket_machine` 或 `gate_machine`）给予方块，放置到世界中即可生效。
- 设置闸机站点：使用“车站设置器”工具（插件提供的物品），对检票机右键，按界面提示选择线路、站点与入/出站模式并保存。
- 设置线路价格：两种方式：
  - In-game 命令：`/setline price (lineid)`（视插件实现）
  - Web 面板首页为每条线路提供价格设置表单
- 手动同步：Web 面板首页点击“手动同步云端数据”或调用 `/syncdata`（视实现）

## 玩家流程

1. 前往售票机，选择出发线路、起点与终点（GUI）。
2. 插件通过 Vault 扣费，成功后玩家得到一张车票（书页形式，包含线路、始发站、终点与价格）。
3. 在入站检票机处使用车票右键入站：若车票线路与站点匹配且未过期，则开闸。
4. 到达终点在出站检票机使用车票右键：若为终点且有效，则开闸并消费（移除）车票。
