# Web 管理面板（使用指南）

访问地址：`http://<服务器IP>:<web.port>/`（默认 `2345`，从 `config.yml` 配置）。

功能简介：
- 线路列表：查看所有同步或手动添加的线路，设置价格、进入线路管理。
- 添加线路：在首页表单中填写线路名与可选 ID，提交后可进入站点管理界面。
- 站点管理：单线路页面可添加/编辑/删除站点。
- 车票管理：查看已发放车票、手动发放、撤销或标记已消费。
- 手动同步：首页按钮触发立即同步云端数据（异步任务）。

安全：
- 面板默认无认证。生产环境强烈建议：
  - 将 `security.web-token` 设置为随机 Token，并在前端请求中附带，或
  - 将服务绑定至 127.0.0.1 并通过反向代理（nginx）做认证/访问控制。

开发者提示：接口为普通表单/POST 操作，易于扩展为 AJAX。
