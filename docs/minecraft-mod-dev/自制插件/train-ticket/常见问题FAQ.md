# 常见问答

Q: 闸机为何能双向通行？
A: 确认闸机的 mode 是否正确设置为入站/出站。管理员应使用车站设置器工具设置检票机的站点与模式。

Q: 玩家背包物品无法移动？
A: 插件已修复 InventoryClick 取消逻辑，只会在插件 GUI（标题含“车站:”）中阻止物品操作。若仍有问题，确认是否存在其他插件拦截交互。

Q: 车票是空地图或空书页怎么办？
A: 插件默认使用 WRITTEN_BOOK 写入票面文本。若看到空内容，可能是服务器没有正确写入 PDC 或物品创建逻辑被修改，检查控制台错误。

Q: 如何保护 Web 面板？
A: 在 `config.yml` 中设置 `security.web-token` 并通过反向代理限制访问，或请我为面板添加登录认证。
