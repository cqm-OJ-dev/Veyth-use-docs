# TrainTicket 插件文档（概览）

TrainTicket 是一个面向 Paper/Spigot Minecraft 服务器的车站售检票插件，目标是将真实地铁检票体验引入游戏世界。核心功能包括：

- 可放置的售票机（售票）和检票机（检票/闸机）方块
- 车站设置器工具：对检票机右键设置站点、线路与出/入站模式
- 本地持久化：插件目录下使用 SQLite（stations.db）保存线路、站点、票据与机器配置
- 云端同步：可配置的远程接口定期同步线路与站点数据（JSON API）
- 经济集成：通过 Vault 收费并兼容常见经济插件
- 游戏内 GUI（中文）与 Web 管理面板（可配置端口）

本文档面向服务器管理员、运维人员与二次开发者，采用 Docusaurus 结构组织，便于直接提交到静态文档站点。
